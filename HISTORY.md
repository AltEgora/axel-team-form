# История проекта (чат в claude.ai, 2 ноября 2026)

Краткая хронология разговора, из которого вырос проект: что спрашивали, что решили и почему. Дословная переписка осталась в истории чатов claude.ai.

## 1. Исходная задача
Пользователь прислал презентацию «Командная форма для фигурного катания» (9 слайдов: обложка, 5 разделов работ по 4 заглушки, «Как заказать», финальный призыв со звонком) и попросил сделать сайт со страницей как из презентации — чтобы отправлять клубам индивидуальные предложения на пошив. Весь визуал — с axelnn.ru. Перед разработкой попросил провести интервью и составить ТЗ.

## 2. Интервью → ТЗ
Решения из интервью:
- Персонализация: название клуба в заголовке; суть — клиент смотрит примеры работ, а детали согласует через менеджера.
- Сначала шаблон с заглушками, фото заполнят позже. Механика подстановки клуба и наполнения — «потом».
- Формат: лендинг + галерея по разделам.
- Хостинг: свой сервер; домен есть, но пока работаем по IP.
- Связь: звонок, Telegram, WhatsApp, MAX, форма заявки.
- Поля формы: имя, телефон, клуб, город, количество спортсменов, срок, номера понравившихся работ. Выбор ткани и вида изделия — не в форме, это предлагает менеджер.
- Визуал «как можно ближе» к axelnn.ru. Нужны превью ссылки для мессенджеров и Яндекс.Метрика.
ТЗ оформлено документом (ссылка в CLAUDE.md). В ТЗ отмечен риск: для формы с телефоном нужны согласие на обработку ПДн и политика (152-ФЗ) — добавлено в сайт как шаблон.

## 3. Разработка
- Стиль снят со страницы axelnn.ru через браузер: Montserrat + Playfair Display, переменные цветов (`--teal-deep #0E7A88` и др.), прямые углы, логотип. Иконки разделов и фото катка взяты из презентации и перекрашены в фирменный цвет.
- Сделано: шапка, первый экран, полоса преимуществ, 5 разделов → галерея с номерами работ и отметкой «Хочу так же» (номера сами попадают в заявку), «Как заказать», форма, подвал, нижняя панель «Позвонить» на телефоне, просмотр фото, `?club=` для персонализации, превью ссылки (og.jpg), Метрика с целями.
- Обработчик заявок на Node.js: Telegram + почта + резервная копия в leads.log, защита от спама (ловушка-поле, лимит 5 заявок с IP за 10 минут).
- По просьбе пользователя выложен предпросмотр артефактом в claude.ai (пользователь подтвердил, что делает сайт с согласия «Аксель·НН»). Из-за ограничений артефактов ссылки разделов переделаны на `#kofty` вместо `#works/kofty`.

## 4. Выкладка на сервер
- Подключиться к серверу напрямую из чата не получилось: среда, где Claude выполнял команды на Mac пользователя, не пропускает SSH, а пароли Claude не вводит. Поэтому написан `install.sh` (ставит всё одной командой), пользователь сам скопировал архив и запустил его.
- Сервер на Ubuntu (адрес — в CLAUDE.local.md). Сайт заработал по IP.

## 5. Регламент работы с заявками
Составлен документ: чек-лист до первых рассылок, обработка заявок (ответ за 15 минут, 8 вопросов первого звонка, таблица учёта, повторные касания через 1, 3–4 и 7–10 дней, сбор размеров, схема этапов), из чего складывается индивидуальное предложение (что персонализировать, формула цены, способы нанесения, три пакета, условия, дошив новичкам), шаблоны сообщений, что развивать дальше. Реальные цены и сроки оставлены в [скобках] — их знает только пользователь.

## 6. Telegram-бот
Пользователь спросил, зачем бот, если заявки идут через менеджера. Объяснено: бот нужен только для заявок с формы сайта. Решили: заявки приходят менеджеру лично в Telegram (не в групповой чат), почту пока не настраиваем. Бот создан, ID чата получен, тестовая заявка пришла.

## 7. Проверка полей
Добавлены правила для всех полей (на сайте и на сервере): телефон 11 цифр с маской `+7 (XXX) XXX-XX-XX` и заменой ведущей 8, имя только буквами, город, клуб без мусорных символов, количество 1–500, дата из календаря не раньше сегодня, номера работ только существующие. Найден и исправлен баг: подсказка об ошибке сдвигала форму, и клик по галочке согласия промахивался.

## 8. Выкатка обновлений
Сделан `deploy.sh`: проект живёт на Mac в `~/proj/axel-team-form`, обновление — `./deploy.sh` (проверка файлов → rsync → install.sh). Рекомендовано настроить вход по SSH-ключу (`ssh-copy-id`). Пользователь решил перейти в Claude Code, чтобы правки и выкатку делать оттуда.
