# Сайт-витрина командной формы «Аксель·НН»

Одностраничный сайт, который менеджер отправляет клубам фигурного катания как индивидуальное предложение на пошив командной формы. Клиент смотрит примеры работ, отмечает понравившиеся и оставляет заявку; дальше всё согласует менеджер. Делается для «Аксель·НН» (axelnn.ru) с их согласия. Пользователь пишет по-русски — отвечай по-русски.

История проекта и принятые решения — в `HISTORY.md`. Адрес сервера и ссылки на документы — в `CLAUDE.local.md` (он не в git).

**Репозиторий публичный** (github.com/AltEgora/axel-team-form). В git не кладём: контакты менеджера (`public/config.js`, в репозитории шаблон `config.example.js`), адрес сервера (`.deploy.env`), `server/.env`, логи с заявками, фото работ. Всё это перечислено в `.gitignore`; перед коммитом проверяй `git status`, что приватное не попало.

## Где что

```
public/                 сайт (nginx отдаёт эту папку)
  index.html            вся страница
  config.js             телефон, мессенджеры, срок производства, Метрика — правит пользователь (не в git; шаблон config.example.js)
  data/works.json       разделы и работы (id, category, photo, club, details)
  assets/css/style.css  стили (палитра и типографика axelnn.ru)
  assets/js/app.js      галерея, отметки «Хочу так же», маска телефона, проверка полей, отправка формы
  assets/img/           логотип, фото катка, иконки разделов, og.jpg (превью ссылки)
  assets/works/         сюда класть фото работ
  privacy.html          шаблон политики ПДн (реквизиты не заполнены)
server/                 обработчик заявок, Node.js без фреймворков
  server.js             POST /api/lead → проверка полей → Telegram (+ почта, если задана) + копия в leads.log
  .env                  ТОЛЬКО на сервере: токен бота, ID чата, SMTP. В репозиторий/архив не попадает
install.sh              установка/обновление на сервере (nginx, Node 20, systemd-служба axel-leads)
deploy.sh               выкатка с Mac: проверка файлов → rsync → install.sh на сервере
DEPLOY.md, README.md    инструкции для людей
```

## Сервер

- Ubuntu, адрес — в `CLAUDE.local.md` и `.deploy.env`. Сайт пока по IP, без домена и HTTPS. Вход по SSH-ключу с Mac настроен — deploy.sh можно запускать самому.
- Файлы на сервере: `/var/www/axel-team-form` (копируются туда из `/root/axel-team-form` скриптом install.sh).
- Обработчик заявок — служба `axel-leads` на 127.0.0.1:3005, nginx проксирует `/api/lead`.
- Telegram-бот настроен и работает: заявки приходят менеджеру лично. Почта отключена (`MAIL_TO=` пустой) — так решил пользователь.
- Журнал: `journalctl -u axel-leads -n 20 --no-pager`. Все заявки также в `/var/www/axel-team-form/server/leads.log`.
- Домен с HTTPS: `bash install.sh forma.example.ru` на сервере (certbot ставится сам).

## Как выкатывать

```bash
cd ~/proj/axel-team-form && ./deploy.sh
```
Правки делаются ТОЛЬКО здесь, локально, не на сервере — иначе следующий deploy их затрёт. `server/.env` и `leads.log` на сервере deploy не трогает. Пароль/токены никогда не вписывать в файлы проекта и не выводить в чат.

## Правила, которые нужно соблюдать

- **Визуал как у axelnn.ru:** Montserrat (текст) + Playfair Display (заголовки, uppercase), бирюзовый `#0E7A88` (`--teal-deep`), ink `#1E2A2C`, прямые углы (radius 0), кнопки uppercase с разрядкой и тонкой стрелкой. Переменные — в `:root` в style.css.
- **Проверка полей продублирована** в `public/assets/js/app.js` (объект `RULES`, маска телефона) и в `server/server.js` (функция `validate`). Меняешь правило — меняй в обоих местах. Телефон: 11 цифр, +7, после +7 цифра 3/4/8/9; хранится как `+7 (XXX) XXX-XX-XX`.
- Сервер берёт список существующих номеров работ из `public/data/works.json` — номера работ в заявке проверяются по нему.
- **Навигация по разделам — хэш вида `#kofty`** (без слэшей): так работает и на сайте, и в предпросмотре-артефакте claude.ai.
- `?club=Название` в ссылке подставляет название клуба в шапку и в поле «Клуб» формы (персонализация предложения).
- Mobile-first: основной сценарий — ссылка из мессенджера на телефоне. Проверяй ширины 390 и 1440.
- Фото с лицами детей — только с согласия родителей/клуба; по умолчанию снимать изделия без лиц.

## Проверка перед выкаткой

- `node --check public/assets/js/app.js && node --check server/server.js`
- `python3 -c "import json; json.load(open('public/data/works.json'))"` (deploy.sh делает это сам)
- Локально: `cd server && LEADS_LOG=/tmp/leads.log node server.js` и раздать `public/` любым статик-сервером с прокси `/api/lead` → 127.0.0.1:3005.
