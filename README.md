# Сайт-витрина командной формы «Аксель·НН»

Одностраничный сайт по мотивам презентации. Внешний вид повторяет axelnn.ru: бирюзовый #0E7A88, шрифты Montserrat и Playfair Display, прямые углы, заголовки прописными буквами.

```
public/            ← сайт (это отдаёт nginx)
  index.html       ← страница
  privacy.html     ← политика конфиденциальности (ШАБЛОН — заполнить)
  config.js        ← телефон, мессенджеры, срок производства, Метрика
  data/works.json  ← разделы и работы
  assets/          ← стили, скрипт, картинки
server/            ← обработчик заявок (Telegram + почта)
DEPLOY.md          ← как запустить на сервере
```

## Перед запуском заполнить

Всё в `public/config.js`. Его нет в репозитории (там контакты), поэтому в новой копии сначала: `cp public/config.example.js public/config.js`.

- `telegram`: ссылка на Telegram менеджера, например `https://t.me/username`.
- `whatsapp`: ссылка вида `https://wa.me/79XXXXXXXXX`.
- `max`: ссылка на профиль в MAX.
- `productionTerm`: срок производства, например `'10–14 рабочих дней'`.
- `managerName`: имя менеджера, необязательно.
- `metrikaId`: номер счётчика Яндекс.Метрики (см. ниже).

Если какое-то поле оставить пустым (`''`), соответствующая кнопка на сайте пропадёт.

В `public/privacy.html` заполните реквизиты в [квадратных скобках] и согласуйте текст с юристом.

## Как добавить работы

1. Положите фото в папку `public/assets/works/`. Подойдут JPG или WebP шириной около 1200 px, до 300 КБ. Называйте файлы латиницей без пробелов, например `kofta-olimp.jpg`.
2. Откройте `public/data/works.json` и заполните нужную работу:

```json
{ "id": 1, "category": "kofty", "photo": "assets/works/kofta-olimp.jpg",
  "club": "СШОР «Олимп»", "details": "Бирюзовый/белый, вышивка логотипа, 24 шт." }
```

- `id` — номер работы. Его клиент называет менеджеру, он же приходит в заявке. Номера должны быть уникальными.
- `category` — раздел: `kofty`, `kostyumy`, `zhilety`, `ofp` или `aksessuary`.
- Пока `photo` пустое, на месте фото показывается заглушка с иконкой.
- В разделе может быть сколько угодно работ: скопируйте строку и поменяйте `id`.
- Следите за запятыми между строками: после последней работы запятой нет. Проверить файл можно на jsonlint.com.

## Ссылка с названием клуба

Если добавить к адресу `?club=Название`, сайт подставит название клуба:

```
https://example.ru/?club=СШОР Олимп
```

В шапке появится «Предложение для клуба «СШОР Олимп»», поле «Клуб» в форме заполнится само, а в заявке будет указано, по какой ссылке пришёл клиент. Превью в мессенджерах пока общее для всех клубов. Персональное превью можно сделать следующим этапом.

## Яндекс.Метрика

Создайте счётчик на metrika.yandex.ru и впишите его номер в `metrikaId`. Затем в разделе «Цели» добавьте цели типа «JavaScript-событие» с такими идентификаторами:

| Идентификатор | Что считает |
|---|---|
| `phone_click` | нажатие на телефон |
| `telegram_click`, `whatsapp_click`, `max_click` | нажатия на мессенджеры |
| `category_open` | открытие раздела работ |
| `work_pick` | отметка «Хочу так же» |
| `form_submit` | отправленная заявка |

## Как проверить на своём компьютере

Нужен Node.js. В папке проекта:

```bash
cd server && node server.js          # обработчик заявок на порту 3005
npx serve ../public -l 8080          # сайт на http://localhost:8080 (форма локально не отправится без nginx)
```

Удобнее сразу проверять на сервере по DEPLOY.md.
